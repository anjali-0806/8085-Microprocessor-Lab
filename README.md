# 8085 Microprocessor Assembly Programs

A collection of **8085 microprocessor assembly language programs** developed for learning, laboratory practice, and understanding low-level programming concepts.

This repository contains programs covering arithmetic operations, logical operations, memory manipulation, sorting, and number processing using the Intel 8085 microprocessor.

## 🎯 About the Project

The purpose of this repository is to implement fundamental algorithms using **8085 Assembly Language** and understand how a microprocessor performs arithmetic, logical, and data manipulation operations at the hardware level.

Each program is maintained as a separate file for easy reference, execution, and modification.

## 🧮 Programs Included

| S.No. | Program | Description |
|---:|---|---|
| 1 | `addition_using_registers.asm` | Addition using registers |
| 2 | `basic_8bit_logical_operations.asm` | Basic 8-bit logical operations |
| 3 | `block_transfer.asm` | Block transfer of data in memory |
| 4 | `dad_16bit_addition.asm` | 16-bit addition using DAD |
| 5 | `division.asm` | Division of two 8-bit unsigned numbers |

| 11 | Descending order | Sorting 8-bit numbers in descending order |

## 🛠️ Tools and Technologies

- **Processor:** Intel 8085
- **Programming Language:** 8085 Assembly Language
- **Execution:** 8085 microprocessor kit or a compatible simulator
- **Version Control:** Git and GitHub

## 🚀 How to Use

1. Clone or download this repository.
2. Open the desired assembly program in an 8085-compatible simulator or development environment.
3. Enter the required input data into the specified memory locations.
4. Assemble and execute the program.
5. Verify the output in the designated registers or memory locations.

*Note: Input addresses, output addresses, and execution steps may vary by program. Refer to the comments or instructions in each file.*

## 📖 Learning Objectives

Through these programs, I am developing practical understanding of:

- 8-bit arithmetic and logical operations
- Register pairs and memory addressing
- Conditional and unconditional branching
- Loops and counter-based operations
- Data transfer and manipulation
- Sorting and comparison algorithms
- Low-level programming and microprocessor architecture
